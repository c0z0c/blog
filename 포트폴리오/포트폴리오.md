## 소개

**"Mission-Critical 환경의 신뢰성을 AI 서비스에 이식하는 엔지니어"**

철도 및 전력 시스템 분야에서 20년간 종사하며, 고신뢰성 시스템을 개발해왔습니다. IEC 62443 보안 표준과 KTC 인증을 준수하는 소프트웨어를 설계하며, **10건의 특허 등록**을 통해 기술적 난제 해결 능력을 입증했습니다.

현재는 이러한 엔지니어링 베이스 위에 **LLM, Vision, RAG 기술**을 접목하여, 단순한 모델 구현을 넘어 **'서비스 가능한(Serving) 견고한 AI 시스템'**을 구축하는 데 주력하고 있습니다.

## 주요 프로젝트

### AI 엔지니어링

#### 1. [팀] 나노코코아 - SaaS 광고 콘텐츠 생성 플랫폼
> **Role:** 시스템 아키텍트 & 데이터 파이프라인 | **Tech:** FastAPI, MSA, Docker, FLUX.1-dev
* **개요:** 소상공인을 위한 광고 문구·이미지·랜딩페이지 원스톱 자동 생성 시스템
* **핵심 성과:**
    * **속도 혁신:** 초기 Load/Unload 방식(600초)의 한계를 **경량 모델 상주(In-Memory) 아키텍처**로 고도화하여 **90% 단축 (60초)**
    * **자원 최적화:** L4 GPU(24GB) VRAM 제약을 극복하기 위해 **최적 경량 모델 발굴** 및 FP16 양자화 적용
    * **문제 해결:** Diffusion 모델의 한글 렌더링 한계를 **HTML/CSS 텍스트 렌더링 후 합성 방식**으로 대체하여 **오타율 0%** 달성
* [GitHub 저장소](https://github.com/c0z0c/codeit-ai-3team-ad-content) | [시연 영상](https://youtu.be/YG-xEIOPDD8)

#### 2. [팀] RAG 기반 나라장터 입찰 문서 검색 시스템
> **Role:** 임베딩 엔지니어 (PM) | **Tech:** LangChain, FAISS, OpenAI, Streamlit
* **개요:** 공공조달 PDF/HWP 문서 내 복잡한 정보를 자연어 질의로 추출하는 RAG 시스템
* **핵심 성과:**
    * **비용 절감:** 전처리 최적화 및 불필요한 메타데이터 제거로 원본 대비 **토큰 절감**
    * **검색 품질:** **파일 해시(SHA-256) 기반 중복 제거** 로직 구현 및 HWP 표 데이터 마크다운 변환 파이프라인 자체 개발
* [GitHub 저장소](https://github.com/c0z0c/codeit_ai_g2b_search) | [시연 영상](https://youtu.be/rFoyNxsR5cE)

#### 3. [개인] H2 Map - 실시간 수소충전소 지도 서비스
> **Tech:** Google Cloud Run, Flask, Kakao Map API
* **Serverless 아키텍처:** Cloud Run을 활용하여 트래픽이 없을 때 비용이 발생하지 않는 **비용 효율적 구조(Scale-to-Zero)** 구현
* **실시간 처리:** 공공데이터 포털 API 연동 및 WebSocket 알람 시스템 구축
* [서비스 바로가기](https://h2map-p4wpy5hxaa-du.a.run.app)

#### 4. [개인] PDF RAG 검색 시스템
> **Tech:** OpenAI Embeddings, FAISS, pymupdf4llm
* **2-Stage 검색:** '요약문 검색 → 원본 정밀 검색' 파이프라인으로 Hallucination 최소화 및 정확도 향상
* [GitHub 저장소](https://github.com/c0z0c/pdf_search_openai) | [시연 영상](https://youtu.be/Iv18gd7ouDA)

## 시스템 엔지니어링 경력 (Domain Expertise)

### 철도 통합 방송 및 한전 시스템 (2011 - 2025)
임베디드 리눅스 및 RTOS 환경에서의 고성능 시스템 개발 및 표준화 수행

* **가상 시뮬레이션 환경 구축 (Digital Twin):**
    * 실제 차량 테스트의 물리적/시간적 제약을 극복하기 위해 **차량 신호 시뮬레이터 독자 개발**
    * 개발 및 디버깅 효율 **향상** 및 현장 리스크 최소화 (관련 특허 등록)
* **Mission-Critical 보안 시스템 설계:**
    * 백신 설치가 불가능한 폐쇄망 제약을 극복하기 위해 **경량 해시체인 무결성 검증 시스템** 설계
    * 국제 보안 표준 **IEC 62443-4-1** 기반 보안 설계 및 KCMVP 암호화 모듈 적용
