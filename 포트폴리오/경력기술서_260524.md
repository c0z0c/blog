## 경력 사항

### 1. AI 자동화 컨설팅 — 프리랜서 (2025.06 ~ 현재)

#### AI 자동화 컨설팅 및 시스템 구축

중소 재조업체에 AI 기술 컨설팅 프리랜서로 참여. 사내 AI 도입 전략 수립부터 실제 운영 가능한 자동화 시스템 구축까지 전 과정을 주도.

**AI 인프라 구축 (온프레미스 서버 운영)**

서버를 구축하여 다음 서비스를 직접 운영 중:

- **로컬 n8n 서버** (`n8n-docker`)
  - Docker Compose 기반 self-hosted n8n + PostgreSQL 환경 구성
  - Python 스크립트 연동 가능 환경 구성
  - Cloudflare Tunnel을 통한 외부 webhook 수신 처리
  - 접속: `ssh 58.142.32.228` (dev 계정)

- **OpenClaw AI 에이전트** (`OpenClaw`)
  - 오픈소스 MCP(Model Context Protocol) 게이트웨이 기반 개인 AI 비서 구축
  - Gemini 3.1 Flash-Lite Preview 모델 탑재
  - Telegram Bot을 통한 24/7 접근성 확보
  - Notion API 연동으로 업무 로그·태스크 자동 기록
  - Docker 기반 온프레미스 운영으로 데이터 보안 확보

- **OpenAI Proxy 서버** (`OpenAI`)
  - OpenAI API 프록시 서버 구축
  - 실시간 토큰 사용량 모니터링 대시보드 운영
  - 팀 단위 API 비용 관리 및 사용 현황 분석

**텔레그램 + n8n + LLM + 노션 기반 근태·외근 관리 자동화**

- 텔레그램 명령어(/출근, /퇴근, /외근, /복귀)만으로 근태 기록 자동화
- Gemini 3.1 기반 자연어 파싱으로 정보 누락 시 AI가 대화형으로 보완
- Notion 데이터베이스에 실시간 기록·조회·수정 기능 구현
- 출근 미등록 알림 자동 발송 (공휴일·주말 제외 처리)
- 사용자별 출근 기준 시각 설정, 병렬 알림 발송으로 처리 성능 개선
- 대상 인원 70~80명 규모 운영 검토 및 도입 보고서 작성
- 기술 스택: n8n, Telegram Bot API, Gemini API, Notion API, PostgreSQL, Cloudflare Tunnel, Docker

**텔레그램 + n8n + LLM + 노션 기반 보고서 자동화**

- 텔레그램 채널(외근/출장 공지, 회의실 예약) 자연어 데이터를 LLM으로 정형화
- 프로젝트별 인적 자원 집중도 및 부서별 외부 리소스 소모 현황 정량 측정
- 시간대별 가중치(야간 1.2배, 휴일 1.5배), 직급별 가중치 적용 Activity Score 산출
- 경영 의사결정 지원용 실시간 대시보드 설계
- 기술 스택: n8n, LLM(Claude/Gemini), Telegram Bot API, Notion API

**사내 AI 도입 전략 컨설팅**

- 전사 부서별 1:1 인터뷰 수행 (영업·경영지원·연구소·생산본부)
- 전사 AI 도입 로드맵 수립 및 단계별 검토 보고서 작성
- OpenClaw 기반 사내 문서 관리 시스템 설계안 제안
- Notion MCP 연동 가이드 작성 및 Claude Code AI 에이전트 환경 구성
